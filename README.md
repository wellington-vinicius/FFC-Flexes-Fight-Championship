# 🥊 FFC – Flexes Fight Championship

**WHERE LEGENDS ARE BORN.**

Projeto desenvolvido como atividade prática do curso de Desenvolvimento de Sistemas da Proz.

## 📌 Sobre o projeto

A FFC (Flexes Fight Championship) é uma organização fictícia de MMA, inspirada nas grandes competições internacionais de artes marciais mistas.

O site apresenta a história da organização, grandes nomes do MMA, funcionamento das competições e um sistema demonstrativo de inscrição de novos lutadores.

## 🚀 Funcionalidades

- Página inicial com apresentação da organização.
- Seção sobre a história da FFC.
- Apresentação de grandes nomes do MMA.
- Explicação do processo de seleção e competições.
- Página de inscrição interativa.
- Validação de informações com JavaScript.
- Mensagem de confirmação após a inscrição.

## 🛠️ Tecnologias utilizadas

- HTML5 – Estrutura das páginas.
- CSS3 – Estilização e layout.
- JavaScript – Interatividade e validação do formulário.
